## 背景

需求要求四指下滑打开挂帘。
macOS 把该手势默认映射给调度中心。实现路径由 `E00-S01` 的结论决定。

**警告：** 本 issue 在 `E00-S01` 判定“可交付”之前不要开始实现。
结论为“不可交付”时直接关闭本 issue。

## 目标

按 `E00-S01` 选定的路径实现手势触发源。

## 实施要点

1. 新增一个触发源实现，接入 `E01-S01` 的注册表。
2. 手势识别要有最小滑动距离和最小速度阈值，避免误触发。
3. 手势在挂帘已展开时改为收起，或直接忽略。由 `ADR-003` 的去重规则决定。
4. 权限申请时机：首次启用该触发源时申请，不在启动时申请。
5. 权限被拒时调用 `E01-S05` 的降级路径。

## 验收标准

1. 在真机上四指下滑能打开挂帘。
2. 两指滚动不触发挂帘。
3. 三指手势不触发挂帘。
4. 挂帘已展开时手势行为符合 `ADR-003`。
5. 连续快速滑动不产生重复开关。
6. 触发源可以被单独关闭。
7. 有覆盖阈值判断的单元测试。

## 依赖

`E00-S01`、`E01-S01`。
