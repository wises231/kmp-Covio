## 背景

导航栏用 `ForEach(HubTab.allCases)` 渲染（`HubNavRail.swift:65`）。
内容区用 `switch` 渲染（`HubView.swift:186`）。
两者都绑定在枚举上。数据模型就位后要改成绑定在实例列表上。

用户还需要一个编辑入口来增删改名排序工作区。

## 目标

导航栏渲染数据驱动的工作区列表。用户可以在界面上管理工作区。

## 范围

范围内：

- 替换枚举为实例列表。
- 导航栏渲染。
- 工作区编辑器界面。
- 相关测试改写。

范围外：

- 数据模型与持久化。见 `E03`。
- 每工作区设置界面。见 `E06`。

## 子项

- [ ] `E04-S01` 用工作区实例替换 `HubTab` 枚举
- [ ] `E04-S02` 导航栏渲染动态页签
- [ ] `E04-S03` 工作区编辑器：添加、删除、改名、排序
- [ ] `E04-S04` 改写页签顺序断言与合同测试

## 退出条件

1. 界面上看不到硬编码的页签列表。
2. 用户可以完成增删改名排序四项操作。
3. 改动后重启应用，结果保留。
4. 设计合同测试全部通过。

## 依赖

`E03`。

## 风险

`E04-S04` 必须先于 `E04-S01` 完成，否则测试会在改造中途长期失败。
