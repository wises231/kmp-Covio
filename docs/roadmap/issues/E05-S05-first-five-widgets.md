## 背景

首页需要一组初始组件。组件只做摘要与快捷动作。
完整功能页面见 `E07`。

## 目标

实现五个组件。

## 组件清单

| 组件 | 内容 | 快捷动作 |
| --- | --- | --- |
| 电源 | 电池百分比、合盖状态、空闲规则状态 | 切换保持唤醒、立即睡眠 |
| 剪切板 | 最近三条文本摘要 | 复制最近一条、打开剪切板工作区 |
| 截图 | 最近三张截图的缩略图 | 复制、打开截图工作区 |
| 文件 | 暂存条目数与剩余空间 | 打开文件工作区 |
| 设备 | 在线设备数与传输队列长度 | 打开设备工作区 |

## 实施要点

1. 每个组件实现为一个 SwiftUI 视图，从 `PaneRegistry` 之外的 `WidgetRegistry` 注册。
2. 组件数据来自现有运行时：`AppRuntime`、`ClipboardRuntime`、`ShelfRuntime`、`WorkspaceRuntime`。
3. 组件不直接读写磁盘，只读运行时状态。
4. 每个组件提供小、中、大三档布局。空间不足时按优先级裁剪信息。
5. 界面不显示剪切板正文。这条约束来自产品总稿 6.5 节。
6. 界面不显示文件完整路径。
7. 界面不显示设备 IP 地址。

## 验收标准

1. 五个组件都能渲染数据。
2. 每个组件三档尺寸下都不截断关键信息。
3. 空数据时显示空状态文案，不显示 `0` 或空白。
4. 剪切板组件不显示正文。
5. 文件组件不显示完整路径。
6. 设备组件不显示地址。
7. 深色与浅色模式下颜色来自合同令牌。
8. 每个组件有渲染测试。
