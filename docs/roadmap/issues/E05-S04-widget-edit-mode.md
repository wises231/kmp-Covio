## 背景

挂帘外壳已由 `E02-S03` 增加 `EDITING` 状态。该状态禁止指针移出自动收起。
网格逻辑已由 `E05-S02` 提供。

## 目标

实现组件的拖动、缩放、删除和撤销。

## 实施要点

1. 进入编辑模式后组件出现拖动把手与缩放把手。
2. 拖动时实时吸附，并显示落位预览。
3. 缩放只在可用尺寸档之间切换。
4. 删除用组件上的关闭按钮，单击即删，支持撤销。
5. 撤销用顶部提示条，显示 5 秒。
6. 编辑模式下组件不响应自身的点击动作。
7. 减少动态效果开启时，吸附预览只改变透明度。

## 验收标准

1. 拖动时组件吸附到网格。
2. 拖动不会产生重叠。
3. 缩放只在可用尺寸档之间切换。
4. 删除后出现可撤销提示条。
5. 撤销后组件回到原位与原尺寸。
6. 编辑模式下点击组件不触发其动作。
7. 全部操作立即持久化。
8. 有覆盖拖动与缩放结果的单元测试。

## 依赖

`E05-S02`、`E02-S03`。
