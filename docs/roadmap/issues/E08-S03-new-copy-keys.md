## 背景

合同 `copy` 节保存全部界面文案，每个键带英文与简体中文。
`ContractCopy.swift` 由脚本从合同生成，Swift 侧不写死字符串。
产品总稿 6.6 节有中英对照表。

## 目标

为工作台的全部新界面文案添加合同键。

## 待添加的文案分组

1. 工作区：标题、添加、删除、改名、排序、删除确认、最后一个不可删除的说明。
2. 组件：目录标题、各组件名称与说明、尺寸档名称、空状态说明。
3. 编辑模式：进入、完成、撤销提示、拖动提示。
4. 触发源：四个触发源的名称与说明、权限缺失提示、注册失败提示。
5. 工作区设置：面板标题、无设置说明、恢复默认、重置确认。
6. 设备工作区占位：不可用原因与后续说明。

## 实施要点

1. 每个键同时提供 `en` 与 `zh-Hans`。
2. 文案遵守产品总稿 6.5 节：主动语态、具体动作、一个按钮一个动作。
3. 错误文案写出原因和恢复动作。
4. 权限文案写出用途和影响。
5. 风险文案先写动作，再写后果。
6. 不使用模糊词和宣传词。
7. 同步更新产品总稿 6.6 节的中英对照表。

## 验收标准

1. 全部分组的键齐全，英文与中文都有。
2. 没有空字符串，没有占位符文本。
3. 按钮文案只写一个动作。
4. 产品总稿 6.6 节已同步。
5. 现有 `CopySingleSourceTests.swift` 的 2 条用例继续通过。
