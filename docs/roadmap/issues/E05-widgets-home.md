## 背景

需求要求首页是一个 Widgets 工作区。用户可以在首页放组件。
组件是最小的展示与交互单元。组件可以编辑和设置。

现有 Hub 没有网格概念。页面是整块的列表或表单。

## 目标

实现组件模型、网格布局、组件目录和编辑模式。
首页成为可编辑的组件网格。

## 范围

范围内：

- 组件实例模型与尺寸档。
- 网格布局引擎。
- 组件目录与添加流程。
- 编辑模式。
- 首批五个组件。
- 空状态与默认布局。

范围外：

- 组件的完整功能页面。组件只做摘要与快捷动作，完整页面见 `E07`。
- 每工作区设置界面。见 `E06`。

## 子项

- [ ] `E05-S01` `Widget` 实例模型与尺寸档
- [ ] `E05-S02` 网格布局引擎
- [ ] `E05-S03` 组件目录与添加流程
- [ ] `E05-S04` 编辑模式：拖动、缩放、删除、撤销
- [ ] `E05-S05` 首批五个组件
- [ ] `E05-S06` 空状态与首次启动默认布局

## 退出条件

1. 首页显示组件网格。
2. 组件可以添加、移动、缩放和删除。
3. 布局在重启后保留。
4. 组件在深色模式与浅色模式下都符合合同令牌。

## 依赖

`E04`。组件模型要能嵌进 `E03-S01` 的 `PaneInstance`。

## 风险

网格布局的纯逻辑必须放在 `kmpDomain`，否则无法测试。
SwiftUI 只负责渲染与手势。
