## 4. V03：本地网络授权与 mDNS 浏览

### 4.1 前置条件

1. 两端应用已启动。
2. 两端在同一子网。
3. 应用已声明本地网络用途字符串。

### 4.2 命令或请求

```bash
# 记录权限声明
/usr/libexec/PlistBuddy -c 'Print :NSLocalNetworkUsageDescription' \
  <应用路径>/Contents/Info.plist
```

```bash
# 浏览已声明的服务类型
dns-sd -B _<服务类型>._tcp local.
```

### 4.3 预期结果

1. 第一次浏览触发本地网络授权提示。
2. 允许后能看到对端记录。
3. 拒绝后看不到对端，且不出现第二次提示。
4. 拒绝后界面提供手动输入地址的入口。

## 5. V04：配对（二维码与短码）

### 5.1 前置条件

1. 两端已发现对方。
2. 两端都没有对方的配对记录。

### 5.2 命令或请求

按界面执行以下动作。

1. 在 A 端发起配对，读取二维码与短码。
2. 在 B 端扫描二维码。
3. 记录两端显示的确认码。
4. 在两端确认。

### 5.3 预期结果

1. 两端显示的确认码相同。
2. 配对完成后两端出现在设备列表。
3. 短码在 120 秒后失效。
4. 配对耗时不超过 30 秒。

## 6. V05：确认码不一致时终止

### 6.1 前置条件

1. V04 已完成并清除配对记录。
2. 准备一个模拟对端，用于提供不同的确认码。

### 6.2 命令或请求

```bash
# 启动模拟对端，返回与真实对端不同的确认码
covio-test-peer --pair-mode qr --confirm-code 000000
```

```text
在 A 端发起配对，让 A 端连接到模拟对端
记录 A 端显示的确认码
记录 A 端在确认码不一致时的行为
```

### 6.3 预期结果

1. A 端显示的确认码与模拟对端不一致。
2. 用户确认后配对被终止。
3. 界面给出风险说明。
4. 两端都不保存信任关系。
5. 错误码为 `pair_confirm_mismatch`。

2. 准备一个不小于 200 MB 的测试文件。
3. 记录测试文件摘要。

### 8.2 命令或请求

```bash

```
