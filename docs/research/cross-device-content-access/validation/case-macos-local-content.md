## 5. V02：截图目录监视与元数据判定

### 5.1 前置条件

1. 应用的截图目录监视已开启。
2. 截图保存位置为默认值或已记录的值。
3. 接收目录已备份。

### 5.2 命令或请求

```bash
# 记录监视前的目录清单
ls -la ~/Desktop | head -20
```

```bash
# 触发一次截图，保存到默认位置
screencapture -x /tmp/covio-probe/case1-$(date +%s).png
```

```bash
# 读取扩展属性，确认截图标记
xattr -l /tmp/covio-probe/case1-*.png
```

### 5.3 预期结果

1. 监视器在 5 秒内报告新文件。
2. 扩展属性包含 `com.apple.metadata:kMDItemIsScreenCapture`。
3. 非截图文件不触发上报。
4. 首次访问受保护目录时出现文件夹授权提示。
