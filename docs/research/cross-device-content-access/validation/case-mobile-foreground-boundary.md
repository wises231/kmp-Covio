## 4. V10：iOS 剪切板读取

### 4.1 前置条件

1. iOS 应用已启动。
2. 剪切板已写入无敏感信息的测试文本。
3. 设备未开启任何自动化脚本。

### 4.2 命令或请求

按界面执行以下动作。

1. 在应用前台触发一次读取。
2. 记录系统是否出现粘贴确认提示。
3. 让应用退到后台，再次触发一次读取。
4. 记录后台读取的结果。

### 4.3 预期结果

1. 前台程序化读取出现系统确认提示。
2. 后台读取被系统拒绝，或返回空。
3. 应用不在后台尝试读取。
4. 界面提供用户点击控件的读取入口。

## 5. V11：iOS 相册截图与本地网络

### 5.1 前置条件

1. 设备相册中存在至少三张截图与三张普通照片。
2. 应用的相册授权为完全访问。
3. 两端在同一局域网。

### 5.2 命令或请求

按界面执行以下动作。

1. 在应用中打开截图列表。
2. 记录列出的截图数量与来源。
3. 把相册授权改为受限访问，只选一张截图。
4. 再次打开列表，记录数量变化。
5. 关闭本地网络授权，触发一次向对端的发送。

### 5.3 预期结果

1. 完全访问下能列出全部截图。
2. 受限访问下只列出用户选中的内容。
3. 关闭本地网络授权后连接被拒。
4. 界面给出到系统设置的引导。
5. 拒绝后不出现重复提示循环。

## 6. V12：Android 剪切板焦点限制

### 6.1 前置条件

1. Android 设备的 API 级别不低于 29。
2. 设备未安装默认输入法以外的系统级剪贴板工具。

### 6.2 命令或请求

```bash
# 记录目标 SDK 与权限
adb shell dumpsys package <包名> | grep -E 'targetSdk|READ_MEDIA|ACCESS_LOCAL'
```

```bash
# 写入测试文本
adb shell am broadcast -a clipper.set -e text 'covio-test'
```

```text
让应用处于前台并成为焦点，触发一次读取，记录结果
把应用切到后台，保持剪切板内容不变，触发一次读取，记录结果
让另一应用成为焦点，触发一次读取，记录结果
```

### 6.3 预期结果

1. 前台且获得焦点时可以读到内容。
2. 应用不在焦点时读取返回空。
3. 变更监听器在应用不在焦点时不触发。
4. 应用不在后台轮询剪切板。
