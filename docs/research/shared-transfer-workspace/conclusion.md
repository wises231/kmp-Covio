# 结论与限制

> 本文件承载结论摘要、决策因素、决策表、不采用方案、限制和未决项。

## 1. 结论摘要

共享暂存工作区可行。
四个平台各有一个不需要额外授权的放入入口。
Android 用分享意图，Windows 与 macOS 用拖放，iOS 用分享扩展。
工作区需要独立存储，不能复用现有晾衣线的条目模型。
副本放在应用私有数据目录，不放在缓存目录。
移动端的大文件传输有系统上限。
Windows 的分享面板入口需要打包身份，这是一个产品决策点。
iOS 的副本目录决定备份与清理行为，这是第二个产品决策点。
iOS 的后台会话只支持 HTTP，这是第三个产品决策点。
隔空投送不提供共享副本与过期，本主题的增量在这两项（`E-22`）。
结论按证据编号引用 [evidence.md](evidence.md)。

## 2. 决策因素

### 2.1 主要因素

**F1：现有晾衣线不是内容仓库。**
条目只有路径与加入时间（`E-02`）。
条目引用用户原文件，不复制内容（`E-02`）。
原文件移动后条目消失（`E-02`）。
推论是跨设备副本不能建在现有模型上。

**F2：工作区数据不能放在缓存目录。**
Android 会在存储紧张时删除缓存文件（`E-09`）。
Windows 存储感知会清理用户临时文件（`E-15`）。
官方要求应用自己管理缓存（`E-09`）。
推论是工作区必须放在应用拥有的持久目录。

**F3：Windows 分享面板需要包身份。**
分享目标必须有包身份（`E-12`）。
未打包应用没有替代注册路径（`E-12`）。
拖放不需要包身份（`E-13`）。
推论是 Windows 的默认入口是拖放。

**F4：移动端后台传输有硬上限。**
前台服务需要声明类型（`E-10`）。
`dataSync` 类型有 6 小时每 24 小时的配额（`E-10`）。
Doze 期间作业调度不运行（`E-10`）。
推论是移动端大文件传输需要断点与超时处理。

### 2.2 次要因素

**F5：平台目录尚未实现。**
只有两个 actual，JVM 那份返回 macOS 路径（`E-04`）。
工作区在三个平台上没有可用的根目录（`E-04`）。

> 2026-10-13 更新：JVM 那份已按操作系统返回 Windows（`%LOCALAPPDATA%`）与 Linux（`XDG_DATA_HOME`）的根目录。
> iOS 与 Android 的目标还没进构建，两个 actual 仍缺。
> 现状见 `solution.md` 第 10.1 节。

**F6：Android 的放入入口不需要授权。**
分享意图接收方不需要存储权限（`E-06`）。
写入自有文件不需要存储权限（`E-07`）。
全盘访问权限的审核门槛高（`E-08`）。
推论是 Android 不触发商店审批。

**F7：产品参数已经确定。**
保留期 30 天，容量上限 5 GB，可置顶（`E-05`）。
分块传输、摘要校验、断点续传、默认 3 并发（`E-05`）。

**F8：保留策略已有实现可以先例。**
剪切板已有去重、过期、置顶与双上限（`E-03`）。
策略是纯函数，便于测试（`E-03`）。

**F9：接收方持有的 URI 授权会失效。**
授权随接收方任务栈结束而失效（`E-11`）。
推论是接收方必须先落盘再传输。

### 2.3 iOS 专项因素

**F10：iOS 的放入入口只能是分享扩展。**
分享面板只列出扩展（`E-16`）。
扩展与主应用不共享容器（`E-17`）。
扩展内存受限，且随时可被终止（`E-17`）。
推论是扩展只落盘，传输交给主应用。

**F11：iOS 的副本目录决定备份行为。**
缓存与临时目录会被系统清理（`E-19`）。
`Documents` 与 `Library` 进入 iCloud 备份（`E-19`）。
备份排除标记只是提示（`E-19`）。
推论是副本放 `Library/Application Support`，过期由 Covio 自己执行。

**F12：iOS 的后台会话只支持 HTTP 与 HTTPS。**
后台会话不支持自定义协议（`E-18`）。
用户手动结束应用会取消全部后台传输（`E-18`）。
推论是 iOS 的大文件传输需要 HTTP 端点，或限制在前台。

## 3. 决策表

| 决策 | 选择 | 原因 | 备选路径 |
| --- | --- | --- | --- |
| 拓扑 | 本地优先副本 | 离线可读，不依赖常驻设备 | 常驻托管，手机之间不可用 |
| 存储位置 | 应用私有数据目录 | 缓存目录会被系统清理（F2） | 缓存目录，数据会丢 |
| 条目标识 | 内容摘要 | 天然去重，同名不冲突（F1） | 路径或序号，跨设备不稳定 |
| 大内容策略 | 高于阈值只复制索引，按需取回 | 降低占用与流量 | 全量复制，占用成倍 |
| 删除语义 | 全局传播加 30 天删除标记 | 共享工作区需要一致视图 | 本机删除，两端不一致 |
| 置顶语义 | 本机属性，不传播 | 属于个人偏好 | 全局置顶，语义不清 |
| 过期时间 | 由放入方确定，接收方照抄 | 时钟不一致时以放入方为准 | 各设备自行计算，结果不同 |
| Windows 入口 | 拖放为默认，分享面板为可选 | 分享面板需要包身份（F3） | 只做分享面板，未打包时不可用 |
| Android 存储 | 只写私有目录 | 避免全盘权限与商店审批（F6） | 写公共目录，需要授权 |
| 移动端大文件 | 只在前台窗口内传输 | 前台服务有配额（F4） | 后台常驻，配额耗尽后失败 |
| iOS 放入入口 | 分享扩展 | 分享面板只列扩展（F10） | 只做类型注册，覆盖不足 |
| iOS 副本目录 | 应用容器的 `Library/Application Support` | 缓存目录会被清理（F11） | `Caches`，数据会被系统删除 |
| iOS 大文件传输 | 主应用执行，前台优先 | 扩展不能声明后台模式（F12） | 扩展内传输，内存不足被终止 |
| 相册导出 | 只支持图片与视频 | 音频没有独立的相册资产类型（`E-20`） | 全类型导出，行为未定义 |
| iOS 后台续传 | 新增 HTTP 端点 | 后台会话只支持 HTTP 与 HTTPS（F12） | 只在前台传输，用户需停留 |
| iOS 副本备份 | 设置备份排除标记，不进 iCloud | 工作区是临时内容（F11） | 进入备份，内容随备份离开局域网 |

## 4. 逻辑证据链

### 4.1 观察一：放入入口全部可用

观察：Android 分享意图免权限（`E-06`）。
观察：Windows 与 macOS 拖放免权限（`E-13`）。
观察：Windows 分享面板需要包身份（`E-12`）。
推论：每个平台至少有一个免授权入口。
置信度：高

### 4.2 观察二：存储必须由应用拥有

观察：现有条目只引用路径（`E-02`）。
观察：缓存目录会被系统清理（`E-09`、`E-15`）。
观察：平台目录尚未实现（`E-04`）。
推论：需要新增工作区存储，并补齐目录实现。
置信度：高

> 2026-10-13 更新：JVM 那份已按操作系统给出 Windows 与 Linux 的根目录，macOS 那份不变。
> iOS 与 Android 仍缺，见 `F5` 的更新。

### 4.3 观察三：迁移有硬上限，需要断点

观察：前台服务有类型要求（`E-10`）。
观察：`dataSync` 有 24 小时内的 6 小时配额（`E-10`）。
观察：URI 授权随任务栈结束失效（`E-11`）。
推论：移动端传输必须可中断、可恢复、先落盘。
置信度：高

### 4.4 观察四：iOS 的入口与传输分两层

观察：分享面板只列扩展（`E-16`）。
观察：扩展与主应用靠共享容器交换文件（`E-17`）。
观察：主应用有系统后台传输，且只支持 HTTP 与 HTTPS（`E-18`）。
推论：iOS 的入口在扩展，传输在主应用，两层解耦。
置信度：高

## 5. 不采用方案

| 方案 | 风险 |
| --- | --- |
| 云端中继 | 违反产品约束“不建立云端内容存储” |
| 常驻设备托管作为默认 | 没有常驻设备时手机之间不可用 |
| 只复制索引 | 对端离线时取不到内容，失去离线可读 |
| 副本放入缓存目录 | 系统会清理，用户内容丢失（F2） |
| 申请全盘文件访问权限 | 商店审批门槛高（`E-08`） |
| 复用晾衣线条目模型 | 模型缺少内容归属与摘要（F1） |
| 依赖系统清理执行过期 | 各平台行为不同，不可控 |
| 复用隔空投送通道 | iOS 没有第三方接口（`E-22`） |
| iOS 扩展内直接传输 | 扩展内存受限且随时终止（`E-17`） |

## 7. 限制和未决项

### 7.1 系统限制

1. 移动端后台传输有时间配额。
2. 缓存目录与临时目录的内容会被系统清理。
3. Windows 分享面板需要包身份。
4. 接收方持有的内容授权会随任务栈结束失效。
5. 各平台私有目录的位置不同。
6. iOS 扩展的内存与执行时间受系统限制。
7. 用户手动结束 iOS 应用会取消后台传输。

### 7.2 产品限制

1. 本地优先副本使占用随设备数成倍增长。
2. 全局删除无法只对单台设备生效。
3. 撤销设备不删除对端已有副本。
4. 移动端无法做到后台无感接收。
5. 分享入口的可用性取决于系统界面。
6. iOS 副本可能随设备备份进入 iCloud。
7. 相册导出不覆盖音频。

### 7.3 未决项

1. HTTP 端点的范围：只覆盖续传，还是覆盖全部传输。
2. macOS 拖入窗口的沙盒授权范围。
3. 是否有必要为 Windows 做打包发行。
4. 按需阈值的默认值是否取 50 MB。
5. 移动端是否默认只保存索引。
6. 厂商定制系统的目录与清理差异。
7. 删除传播是否需要“仅本机删除”选项。

### 7.4 已决项

1. iOS 副本不进 iCloud 备份，用备份排除标记。
2. iOS 后台续传增加 HTTP 端点。
