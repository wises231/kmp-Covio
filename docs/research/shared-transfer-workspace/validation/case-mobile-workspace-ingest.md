## 4. V04：iOS 分享扩展放入

### 4.1 前置条件

1. 分享扩展已在系统中启用。
2. 应用至少启动过一次。
3. 相册中存在一张样例图片。

### 4.2 命令或请求

```text
在相册中选择样例图片，打开分享面板，选择 Covio
记录条目是否生成，以及生成耗时
在文件 App 中选择样例 PDF，重复上述动作
记录扩展对文件类型与大文件的行为
```

### 4.3 预期结果

1. 分享面板中出现 Covio。
2. 图片与 PDF 都生成条目。
3. 条目在手机上状态为 `local`。
4. 超大文件在扩展中给出提示，并转入主应用传输。
5. 扩展关闭后条目仍然存在。
6. 内容经 App Group 共享容器交给主应用（`E-17`）。

## 5. V05：iOS 后台传输

### 5.1 前置条件

1. V04 已完成。
2. 对端在线。
3. 准备一个不小于 300 MB 的样例文件。

### 5.2 命令或请求

```text
在对端放入 300 MB 样例文件
在手机上接收，等待传输开始
把应用切到后台，锁屏
等待 2 分钟后回到前台
记录传输是否继续、是否完成、是否重新开始
```

### 5.3 预期结果

1. 应用在后台时传输不中断，或暂停后自动恢复。
2. 传输完成后两端摘要一致。
3. 应用被系统终止后重新打开时任务继续。
4. 记录后台传输的实际时长上限。
5. 记录用户手动结束应用后的行为（`E-18`）。
6. 记录后台续传使用的协议与端点。

## 6. V06：Android 分享意图放入

### 6.1 前置条件

1. Android 端已安装测试构建。
2. 应用至少启动过一次。
3. 准备图片、音频与 PDF 各一个。

### 6.2 命令或请求

```bash
# 记录意图过滤器与权限
adb shell dumpsys package <包名> | grep -A5 'android.intent.action.SEND'
```

```text
在相册分享样例图片给 Covio
在文件管理器中分享 PDF 给 Covio
在音乐应用中分享音频给 Covio
记录每条条目的 kind 与生成耗时
```

### 6.3 预期结果

1. 三种类型都出现在分享面板并生成条目。
2. 条目状态为 `local`。
3. 应用被系统冻结后再次分享时可以唤醒应用。
4. 授权过期时给出可读的错误。

## 7. V07：Android 私有目录清理行为

### 7.1 前置条件

1. V06 已完成。
2. 工作区中有若干条目。
3. 设备剩余空间可控。

### 7.2 命令或请求

```bash
# 记录工作区占用与目录
adb shell run-as <包名> du -sh files/workspace cache 2>/dev/null
```

```text
记录工作区放在 files 目录还是 cache 目录
查看系统的存储配额分配结果
在设备存储紧张或清理缓存后记录条目是否消失
```

### 7.3 预期结果

1. 工作区位于应用私有 `files` 目录，不位于 `cache` 目录。
2. 系统清理缓存后工作区条目仍然存在。
3. 应用自身的配额淘汰不因系统清理而触发。
4. 记录系统对应用私有目录的实际行为。
