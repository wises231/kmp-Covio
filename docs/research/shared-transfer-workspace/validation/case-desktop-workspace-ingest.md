## 4. V01：macOS 拖放放入与去重

### 4.1 前置条件

1. 应用已启动并显示工作区面板。
2. 工作区目录已备份。
3. 第一次拖放前工作区为空。

### 4.2 命令或请求

```text
把样例 PDF 从访达拖到工作区面板
记录条目数与 entry_id 前 8 位
再次拖入同一个文件
记录条目数变化
```

```bash
# 记录内容目录与索引
ls -l "<工作区目录>/objects"
python3 -c "import json,sys;d=json.load(open('<工作区目录>/index.json'));print(len(d.get('entries',[])))"
```

### 4.3 预期结果

1. 第一次拖放生成一条条目。
2. 第二次拖入相同文件不新增条目。
3. 条目状态为 `local`。
4. `objects` 中只存在一份内容。
5. 工作区面板显示条目卡片。
6. 沙盒构建能读取被拖入的文件（`E-21`）。
