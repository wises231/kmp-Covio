# 前因与问题边界

> 本文件承载问题类别、研究问题、适用范围、受影响角色、系统模型、状态矩阵、场景和成功标准。

## 1. 问题类别与研究问题

### 1.1 问题类别

本文处理一类内容分发问题。
多台设备需要共享一个临时的内容暂存区。
用户在任意设备上主动放入内容。
其他设备在同一暂存区中看到并取出内容。
平台用沙盒、分享入口和后台限制控制放入与取出。

### 1.2 研究问题

安装 Covio 之后，用户能否在 macOS、Windows、iOS 和 Android 上把内容主动推入一个共享暂存工作区？
其他已配对设备能否读取该工作区？
内容类型包括文件、图片、音频、PDF 和文本。

研究问题拆成四个子问题。

1. 放入入口：每个平台有哪些系统入口可以把内容交给 Covio？
2. 一致性：工作区内容如何在已配对设备之间保持一致？
3. 生命周期：配额、过期、冲突和清理如何处理？
4. 安全边界：明文落盘、设备撤销和残留如何控制？

### 1.3 问题定义

工作区是一组已配对设备共享的临时内容集合。
工作区不是云盘。
工作区不依赖账号。
每台设备保存一份本地副本。
内容的来源是用户的主动动作，不是后台采集。
因此本文的能力边界由三条线决定。
三条线是放入入口、复制策略和本地存储限制。

### 1.4 触发条件

满足任一条件时，本文适用。

1. 用户希望把一台设备上的文件送到另一台设备。
2. 用户希望一次放入的内容被多台设备看到。
3. 用户希望在无账号条件下完成上述动作。
4. 用户希望内容不经过云端。
5. 用户希望内容在一段时间后自动消失。

## 2. 范围

### 2.1 适用范围

1. 四个平台上的内容放入入口。
2. 工作区在设备之间的复制策略。
3. 工作区的配额、过期与清理规则。
4. 工作区的安全与隐私边界。
5. 与现有剪切板同步和截图能力的关系。

### 2.2 范围外事项

1. 账号体系与云端内容存储。
2. 跨网段与公网传输。
3. 多人协作与共享文件夹权限。
4. 持久归档与备份。
5. 系统原生投送通道的内部实现。
6. 应用商店上架审核。

## 3. 受影响角色

| 角色 | 关注点 |
| --- | --- |
| 设备所有者 | 放入是否顺手，取出是否找得到，内容是否按时消失 |
| 接收方设备 | 何时能看到内容，是否需要前台，占用多少空间 |
| 产品经理 | 与隔空投送和网盘的差异，能力宣称是否站得住 |
| 研发 | 复制策略、冲突处理、断点续传与平台入口差异 |
| 测试 | 跨平台组合、离线排队、配额上限与清理 |
| 安全与隐私 | 明文落盘范围、设备撤销后的残留、过期是否可靠 |

## 4. 系统模型

### 4.1 组件

| 组件 | 职责 | 位置 |
| --- | --- | --- |
| 放入入口 | 把外部内容交给 Covio | 每台设备本机 |
| 工作区索引 | 记录条目、来源设备、大小与过期时间 | 每台设备本机 |
| 内容副本 | 保存内容的实际字节 | 每台设备本机 |
| 复制引擎 | 在设备之间同步索引与内容 | 局域网 |
| 配额管理器 | 统计占用并执行淘汰 | 每台设备本机 |
| 清理器 | 按过期时间删除条目 | 每台设备本机 |
| 会话通道 | 加密传输与身份校验 | 局域网 |
| 配对服务 | 建立信任关系 | 首次配对时 |

### 4.2 参与者

| 参与者 | 说明 |
| --- | --- |
| 放入方设备 | 发起内容放入的设备 |
| 接收方设备 | 保存副本并展示内容的设备 |
| 系统分享面板 | 提供放入入口的系统界面 |
| 系统授权服务 | 相册、媒体库、文件与本地网络授权 |
| 存储子系统 | 提供容量并执行系统级清理 |

### 4.3 生命周期

```text
放入 -> 加入本地索引 -> 生成摘要 -> 通知已配对设备 -> 对端排队
     -> 传输与校验 -> 对端落盘 -> 双向可见 -> 过期或手动删除 -> 清理残留
```

### 4.4 状态变化

| 阶段 | 正常 | 异常 |
| --- | --- | --- |
| 放入 | 入口可用，内容进入工作区 | 入口被系统限制，改为拖放或应用内选择 |
| 索引 | 条目写入并落盘 | 落盘失败，只在内存保留 |
| 复制 | 对端在线并接收 | 对端离线，进入排队 |
| 落盘 | 校验通过并移动到位 | 空间不足或校验失败 |
| 展示 | 两端看到同一条目 | 两端条目不一致，需要重新同步 |
| 清理 | 按过期时间删除 | 清理未执行，占用超限 |

## 5. 状态矩阵

矩阵的行是设备状态。
矩阵的列是工作区操作。

| 状态 | 放入 | 浏览本机副本 | 浏览对端条目 | 取出内容 | 删除 | 置顶 |
| --- | --- | --- | --- | --- | --- | --- |
| 桌面前台 | 可用 | 可读 | 可读 | 可用 | 可用 | 可用 |
| 桌面后台 | 可用 | 可读 | 可读 | 可用 | 可用 | 可用 |
| 移动前台 | 可用 | 可读 | 可读 | 可用 | 可用 | 可用 |
| 移动后台 | 条件可用 | 可读 | 不可读 | 不可用 | 不可用 | 不可用 |
| 屏幕锁定 | 可用 | 可读 | 可读 | 可用 | 可用 | 可用 |
| 对端离线 | 排队 | 可读 | 过期视图 | 可用 | 可用 | 可用 |
| 空间不足 | 拒绝 | 可读 | 可读 | 条件可用 | 可用 | 可用 |
| 权限被拒绝 | 不可用 | 可读 | 不可用 | 不可用 | 条件可用 | 条件可用 |
| 不同网段 | 排队 | 可读 | 过期视图 | 可用 | 可用 | 可用 |

`条件可用` 表示能力存在，但受对端状态、权限或系统限制。
`排队` 表示任务保留，等对端上线后继续。
`过期视图` 表示只显示索引，内容不可取。

矩阵每一格的依据见 [investigation.md](investigation.md)。
矩阵每一格的证据编号见 [evidence.md](evidence.md)。

## 6. 场景定义

### 6.1 桌面到移动

用户在桌面放入一个 PDF。
手机在后台，任务排队。
用户打开手机应用，条目出现并可取出。

### 6.2 移动到桌面

用户在手机相册选中三张图片并分享给 Covio。
桌面常驻接收并保存副本。
两端的 `Files` 页签显示同一条目。

### 6.3 手机到手机

两台手机在同一局域网。
放入方在前台完成放入。
接收方在前台时收到条目。

### 6.4 大文件与网络中断

用户放入一个 2 GB 的视频。
传输中断后任务暂停。
网络恢复后从断点继续。

### 6.5 过期与配额

工作区达到空间上限。
配额管理器淘汰最旧的未置顶条目。
置顶条目不被淘汰。

### 6.6 设备撤销

用户撤销一台已配对设备。
该设备不再收到新条目。
本机不因撤销而删除已有副本。

## 7. 成功标准

1. 四个平台各有一个可用的放入入口。
2. 每个入口有明确的授权要求与拒绝后的降级路径。
3. 工作区在两台设备上的条目一致。
4. 冲突、过期和配额有确定规则。
5. 离线设备上线后能补齐条目。
6. 每个结论有证据编号。
7. 已知缺口单独列出。
8. 验证计划覆盖至少两个跨平台组合。
