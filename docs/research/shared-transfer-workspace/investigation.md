# 调研方法与技术分析

> 本文件承载调研方法、领域模型、约束模型、现有能力矩阵、源码分析和方案对比。

## 1. 调研方法

调研分两路并行执行。

1. Android 与 Windows：官方行为文档、AOSP 文档、Microsoft Learn 参考页与商店政策页。
2. Apple 平台：接口文档、扩展机制说明与后台执行限制。

本机只读实验覆盖 macOS 端的存储与现有实现。
每一格能力结论都带证据编号。
证据编号指向 [evidence.md](evidence.md)。
上一主题已确认的读取限制直接引用，不重复取证。

## 3. 领域模型

### 3.1 参与者

| 参与者 | 说明 | 关键属性 |
| --- | --- | --- |
| 放入方设备 | 发起内容放入 | 前台状态、可用入口 |
| 接收方设备 | 保存副本并展示 | 在线状态、剩余空间、前台状态 |
| 系统分享面板 | 提供放入入口 | 是否列出 Covio、授权范围 |
| 系统授权服务 | 相册、媒体库、本地网络 | 授权状态 |
| 存储子系统 | 提供容量并执行系统清理 | 配额、清理策略 |

### 3.2 组件

| 组件 | 职责 | 出现位置 |
| --- | --- | --- |
| 放入入口 | 接收外部内容 | 每台设备本机 |
| 条目索引 | 记录元数据与状态 | 每台设备本机 |
| 内容仓库 | 保存内容字节 | 每台设备本机 |
| 复制引擎 | 同步索引与内容 | 局域网 |
| 配额管理器 | 统计占用并选择淘汰 | 每台设备本机 |
| 清理器 | 删除过期与残留 | 每台设备本机 |

### 3.3 生命周期

```text
安装 -> 配对 -> 放入 -> 索引 -> 复制 -> 落盘 -> 可见 -> 过期或删除 -> 清理
```

### 3.4 数据流

```text
外部内容 -> 放入入口 -> 临时文件 -> 摘要计算 -> 内容仓库
                                            |
                                            v
                                        条目索引 -> 复制引擎 -> 对端索引 -> 对端内容仓库
```

索引先于内容传播。
内容按阈值决定是立即复制还是按需取回。

## 4. 约束模型

### 4.1 三类约束

| 约束 | 说明 | 影响 |
| --- | --- | --- |
| 存储约束 | 私有目录、缓存清理、平台目录差异 | 工作区必须由应用拥有，不能放缓存目录 |
| 会话约束 | 移动端后台受限，前台服务有配额 | 复制只能在允许的窗口内进行 |
| 入口约束 | 分享面板、拖放与选择器的能力不同 | 每个平台需要独立的入口实现 |

### 4.2 控制路径

内容进入工作区有三条路径。

1. 系统分享入口：用户在系统界面里选择 Covio。
2. 应用内入口：用户把内容拖入窗口，或在应用内选择。
3. 现有能力转入：剪切板条目与截图保存到工作区。

第三条路径不用新增授权。
第一条路径在 Windows 上需要包身份。

### 4.3 信任边界

| 边界 | 内侧 | 外侧 | 保护手段 |
| --- | --- | --- | --- |
| 设备边界 | 本机工作区 | 已配对设备 | 配对密钥与授权范围 |
| 网络边界 | 局域网 | 其他网络 | 不建立云中继 |
| 存储边界 | 应用私有目录 | 公共目录与相册 | 只写私有目录 |
| 会话边界 | 前台窗口 | 后台 | 只在前台窗口内传输大文件 |
| 传播边界 | 索引 | 内容字节 | 阈值控制按需取回 |

## 5. 现有能力矩阵

### 5.1 放入入口

| 平台 | 入口 | 限制 | 依赖 | 证据 |
| --- | --- | --- | --- | --- |
| macOS | 拖入窗口 | 沙盒授权范围待实测 | 无 | `E-21` |
| macOS | 应用内选择 | 无 | 无 | `E-02` |
| Windows | 拖入窗口 | 无 | COM 初始化 | `E-13`、`E-14` |
| Windows | 系统分享面板 | 需要包身份 | MSIX 或稀疏包 | `E-12` |
| Android | 系统分享面板 | 需声明意图过滤器 | 无存储权限 | `E-06` |
| Android | 应用内选择 | 无 | 无 | `E-06` |
| iOS | 系统分享面板 | 需要分享扩展 | 扩展启用 | `E-16`、`E-17` |
| iOS | 打开方式菜单 | 只处理单个 URL | 类型注册 | `E-16` |
| iOS | 应用内选择 | 无 | 无 | `E-16` |

### 5.2 存储能力

| 平台 | 私有目录 | 系统清理风险 | 公共目录写入 | 证据 |
| --- | --- | --- | --- | --- |
| macOS | `~/Library/Application Support/Covio` | 无 | 需要用户选择 | `E-01`、`E-04` |
| Windows | `%LOCALAPPDATA%` | 临时目录会被清理 | 无 | `E-15` |
| Android | `files` 目录 | 缓存目录会被清理 | 自有文件免权限 | `E-07`、`E-09` |
| iOS | 应用容器 `Library/Application Support` | 缓存与临时目录会被清理 | 相册需要用途说明键 | `E-19`、`E-20` |

### 5.3 后台传输能力

| 平台 | 后台传输 | 上限 | 证据 |
| --- | --- | --- | --- |
| macOS | 完整 | 无 | — |
| Windows | 完整 | 注销与快速启动会终止 | 见上一主题 `E-39` |
| Android | 前台服务 | 6 小时每 24 小时 | `E-10` |
| iOS | 系统后台会话 | 用户强杀即取消；后台发起受速率限制；只支持 HTTP | `E-18` |

### 5.4 平台风险排序

| 平台 | 主要风险 | 严重度 | 证据 |
| --- | --- | --- | --- |
| Windows | 分享面板需要包身份 | 中高 | `E-12` |
| Android | 前台服务配额与 Doze | 中高 | `E-10` |
| Android | 缓存目录被系统清理 | 中 | `E-09` |
| Windows | 临时目录被存储感知清理 | 中 | `E-15` |
| macOS | 数据目录权限偏宽 | 低 | `E-01` |
| iOS | 扩展内存与执行时间受限 | 中 | `E-17` |
| iOS | 用户强杀应用会取消后台传输 | 中 | `E-18` |
| iOS | 副本可能进入 iCloud 备份 | 中 | `E-19` |
| iOS | 后台会话不支持的协议 | 中高 | `E-18` |

## 6. 权限模型

| 能力 | macOS | Windows | iOS | Android |
| --- | --- | --- | --- | --- |
| 放入内容 | 无 | 无 | 扩展声明 | 意图过滤器 |
| 保存副本 | 无 | 无 | 容器内无 | 无 |
| 写入相册 | 用户选择 | 不适用 | 相册授权 | 媒体权限 |
| 扩展与主应用共享数据 | 不适用 | 不适用 | 应用组 | 不适用 |
| 局域网传输 | 本地网络授权 | 防火墙放行 | 本地网络授权 | 本地网络权限 |

跨设备传递不需要“读取他人设备”这一类授权。
授权只在内容所在的设备上申请。

## 7. 目标产品源码分析

分析对象是仓库快照，分支 `feature/swiftui-macos`。
版本基线是 `0.5.0`，未发布。

### 7.1 现状

| 项目 | 现状 | 证据 |
| --- | --- | --- |
| 晾衣线条目 | 只有路径与加入时间 | `E-02` |
| 晾衣线存储 | 引用原文件，上限 12 条 | `E-02` |
| 保留策略 | 剪切板已实现，晾衣线没有 | `E-03` |
| 平台目录 | 只有 macOS 实现 | `E-04` |
| 跨设备复制 | 没有实现 | `E-04` |
| 配额与过期 | 剪切板有，工作区没有 | `E-03` |

### 7.2 可复用部件

| 部件 | 复用方式 |
| --- | --- |
| `ClipboardStore.prune` | 保留策略的规则蓝本 |
| `ShelfFileNaming` | 重名规则 |
| `ShelfLayout` | 卡片布局 |
| `ShelfStore` | `Files` 页签的本地视图 |

### 7.3 结论

现有实现不能直接扩展成工作区。
原因是条目模型缺少内容归属。
扩展点在于新增存储与策略，复用界面与命名规则。

## 8. 参考实现分析

| 产品 | 模型 | 生命周期 | 对本项目的参考价值 |
| --- | --- | --- | --- |
| 隔空投送 | 定向推送 | 落盘即结束 | 需要接收方同意，无第三方接口（`E-22`） |
| Syncthing | 持续同步 | 无过期 | 索引与块校验参考 |
| LocalSend | 定向推送 | 落盘即结束 | 无配对时的接收确认 |
| 系统共享相册 | 云端副本 | 长期 | 不采用，因为有云端 |

### 8.1 关键观察

定向投送产品不做共享工作区。
同步类产品不做过期。
系统投送通道不向第三方开放内部实现（`E-22`）。
本主题的增量在于合取：共享、临时、无账号。

## 9. 候选方案对比

| 方案 | 成本 | 风险 | 成熟度 | 可维护性 |
| --- | --- | --- | --- | --- |
| 本地优先副本 | 中 | N 倍存储 | 高，有先例 | 高 |
| 常驻设备托管 | 中 | 依赖常驻设备 | 中 | 中 |
| 只复制索引，内容按需 | 中 | 对端离线时取不到 | 中 | 高 |
| 云端中继 | 高 | 违反产品约束 | 高 | 中 |

推荐第一种，并对超过阈值的内容采用按需取回。
第二种在没有常驻设备时不可用。
第三种作为第一种的补充，不作为独立方案。

## 10. 反证和限制

### 10.1 反证

1. Windows 拖放在完整性级别下没有直接的官方场景描述。
2. Android 参考页无法取证，常量语义只由训练页支持。
3. 官方没有给出分享唤醒冻结应用的延迟数值。

### 10.2 限制

1. 本机实验只覆盖 macOS。
2. 没有真机交叉验证。
3. “没有替代入口”类结论是负向证据。
4. Apple 一级文档对拖入窗口的沙盒授权范围有两种表述。

## 11. 已知缺口

1. 厂商定制系统的目录与清理策略差异。
2. 分享唤醒冻结应用的延迟。
3. 存储感知清理临时文件的天数阈值。
4. Android 公共目录允许的 MIME 类型范围。
5. 扩展内存上限、扩展执行时间上限与后台传输上限没有官方数值。
6. iOS 副本是否进入 iCloud 备份待产品确认。
