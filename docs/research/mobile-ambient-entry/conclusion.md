# 根因、结论与限制

> 本文件承载结论摘要、根因、决策表、限制和不采用方案。

## 1. 结论摘要

主屏上滑手势不可实现。
锁屏手势和边缘手势同样不可实现。
iOS 不向第三方应用提供这三类手势的注册接口。
替代入口有六个，按可用性和成本排序。
推荐顺序是主屏交互小组件、锁屏交互小组件、控制中心控件、Action Button、轻点背面加快捷指令、应用内 bottom sheet。
控制中心控件是唯一能“一键打开应用并进入指定工作区”的入口。
交互小组件是唯一能在不打开应用的前提下执行动作的入口。
所有入口都要求用户手动添加一次。
所有入口都支持应用未启动时触发。
本结论不预设实现，实现留给后续单独评审。

## 2. 根因或决策因素

### 2.1 主要因素

主要因素是系统空间的开放性。
iOS 把主屏、锁屏和边缘手势保留给系统行为。
第三方应用只能使用系统开放的接入面。
开放的接入面是 WidgetKit 小组件、控制中心控件、Action Button 和 App Intent（`E-03`、`E-04`、`E-05`、`E-06`）。
因此“主屏上滑带出 bottom sheet”没有对应的系统能力。
证据：`E-02`、`E-03`、`E-04`、`E-05`、`E-06`。

### 2.2 次要因素

次要因素一：版本门槛。
控制中心控件要求 iOS 18 及以上（`E-07`）。
交互小组件要求 iOS 17 及以上（`E-15`）。
轻点背面要求 iOS 14 及以上（`E-21`）。
证据：`E-07`、`E-15`、`E-21`。

次要因素二：用户配置成本。
小组件、控件和 Action Button 都要求用户手动添加（`E-13`、`E-33`）。
证据：`E-13`、`E-33`。

次要因素三：锁定状态限制。
锁定设备上小组件的按钮和开关不生效（`E-18`）。
控件可以要求设备认证（`E-14`）。
证据：`E-14`、`E-18`。

次要因素四：机型限制。
Action Button 只存在于部分机型（`E-24`）。
证据：`E-24`。

## 3. 八个问题的回答

### 3.1 主屏手势、锁屏手势和边缘手势是否开放

不开放。
Apple 的系统集成清单列出 Siri、Spotlight、Shortcuts、Action button、Widgets、Controls、Live Activities、Focus、Visual Intelligence 和 Apple Pencil（`E-03`）。
主屏手势、锁屏手势和边缘手势不在清单中。
WidgetKit 的位置清单列出主屏、Today View、StandBy、CarPlay、锁屏、控制中心、桌面、通知中心和 Smart Stack（`E-04`）。
主屏手势也不在位置清单中。
Human Interface Guidelines 要求应用不要与访问系统 UI 的手势冲突（`E-06`）。
主屏上唯一的第三方交互面是图标长按快速操作，最多 4 个，且会打开应用（`E-05`）。
可用性：不可用。
所需 iOS 版本：不适用。
是否需要用户手动配置：不适用。
能否冷启动：不适用。
证据：`E-02`、`E-03`、`E-04`、`E-05`、`E-06`。

### 3.2 控制中心控件能否一键打开应用并进入指定工作区

可以。
`ControlWidget` 自 iOS 18 起可用（`E-07`）。
`ControlWidgetButton` 用于执行动作或启动应用（`E-08`）。
把按钮的动作设为实现 `OpenIntent` 的 App Intent，系统会打开应用并显示指定条目（`E-10`）。
用 `@Parameter` 传入目标枚举，即可指定工作区（`E-10`）。
App Intent 的 Target Membership 必须同时属于主应用和 Widget 扩展（`E-11`）。
可用性：可用。
所需 iOS 版本：iOS 18.0 及以上。
是否需要用户手动配置：需要，用户把控件添加到控制中心、锁屏或 Action Button。
能否冷启动：可以，控件由 Widget 扩展进程执行，`OpenIntent` 会启动主应用。
证据：`E-07`、`E-08`、`E-10`、`E-11`、`E-12`。

### 3.3 WidgetKit 的交互能力边界

小组件可以包含 `Button` 和 `Toggle`，两者都必须使用接收 App Intent 的初始化器（`E-16`、`E-17`）。
这两个初始化器自 iOS 17.0 起可用（`E-15`）。
其他 SwiftUI 控件在小组件中不生效（`E-17`）。
支持交互的尺寸是 `systemSmall`、`systemMedium`、`systemLarge`、`systemExtraLarge`、`systemExtraLargePortrait`，以及 iPhone 和 iPad 上的 `accessoryCircular` 和 `accessoryRectangular`（`E-16`）。
锁定设备上按钮和开关不生效，系统要求用户认证并解锁（`E-18`）。
点击非按钮和非开关区域会打开应用（`E-19`）。
iOS 18 起新增 `ControlWidget`，把交互面扩展到控制中心、锁屏和 Action Button（`E-07`）。
可用性：可用。
所需 iOS 版本：小组件 iOS 14.0 及以上，交互 iOS 17.0 及以上，控件 iOS 18.0 及以上。
是否需要用户手动配置：需要，用户把小组件或控件添加到系统空间。
能否冷启动：可以，App Intent 默认在 Widget 扩展进程中执行（`E-12`）。
证据：`E-07`、`E-12`、`E-15`、`E-16`、`E-17`、`E-18`、`E-19`。

### 3.4 轻点背面能否触发应用内动作，延迟是多少

可以触发。
轻点背面自 iOS 14 起可用，要求 iPhone 8 或更新机型（`E-21`）。
设置路径是设置 > 辅助功能 > 触控 > 轻点背面。
可选双击或三击。
动作列表包含快捷指令（`E-22`）。
延迟没有 Apple 官方数据（`E-23`）。
可用性：可用。
所需 iOS 版本：iOS 14.0 及以上。
是否需要用户手动配置：需要，用户选择双击或三击并绑定快捷指令。
能否冷启动：可以，快捷指令由 Shortcuts 运行时执行，不要求应用事先运行。
证据：`E-21`、`E-22`、`E-23`。

### 3.5 Action Button 能否触发应用意图

可以。
Action Button 存在于 iPhone 15 Pro 及以后的支持机型（`E-24`）。
用户可以把它绑定到系统功能或一个 App Shortcut（`E-25`、`E-26`）。
系统也提供“打开应用”这一默认功能（`E-26`）。
触发方式是长按，按下时系统显示提示文字（`E-25`）。
iOS 18 起还可以把 `ControlWidget` 放到 Action Button（`E-34`）。
可用性：可用，机型受限。
所需 iOS 版本：放 App Shortcut 要求 iOS 17.0 及以上；放控件要求 iOS 18.0 及以上。
是否需要用户手动配置：需要，用户在设置中指定功能。
能否冷启动：可以。
证据：`E-24`、`E-25`、`E-26`、`E-34`。

### 3.6 App Intent 与 Shortcuts 的接入成本

成本低。
一个动作只需要一个实现 `AppIntent` 协议的结构体，加一个 `perform()` 方法（`E-27`）。
输入用 `@Parameter` 声明（`E-27`）。
要出现在 Shortcuts 和 Siri 中，再实现一个 `AppShortcutsProvider` 类型，用静态数据构造 `AppShortcut`（`E-27`）。
编译期生成元数据，用户安装应用后快捷指令立即可用，不需要手动登记（`E-27`）。
同一套 App Intent 可以同时供小组件、控件和 Shortcuts 使用（`E-03`）。
前台或后台行为用 `openAppWhenRun` 或 `supportedModes` 声明（`E-28`）。
`openAppWhenRun` 自 iOS 16.0 起可用，在 iOS 26.0 起废弃（`E-28`）。
`supportedModes` 自 iOS 26.0 起可用（`E-28`）。
可用性：可用。
所需 iOS 版本：App Intent 自 iOS 16.0 起，App Shortcuts 自 iOS 16.0 起。
是否需要用户手动配置：Shortcuts 中不需要登记；系统空间中需要用户添加。
能否冷启动：可以。
证据：`E-03`、`E-27`、`E-28`、`E-29`。

### 3.7 应用内 bottom sheet 能否满足上滑手感

部分满足。
`presentationDetents` 自 iOS 16.0 起可用（`E-30`）。
默认只有一个 `large` detent（`E-30`）。
提供多个 detent 时，用户可以拖动改变高度（`E-30`）。
该能力只在应用已在前台并呈现 sheet 时可用。
它不能从主屏带出。
可用性：可用，但只在应用内。
所需 iOS 版本：iOS 16.0 及以上。
是否需要用户手动配置：不需要。
能否冷启动：不可以，必须先打开应用。
证据：`E-30`。

### 3.8 每个入口在应用未启动时能否工作

| 入口 | 冷启动 |
| --- | --- |
| 主屏小组件按钮 | 可以 |
| 锁屏小组件按钮 | 可以 |
| 控制中心控件 | 可以 |
| 锁屏控件 | 可以 |
| Action Button | 可以 |
| 轻点背面加快捷指令 | 可以 |
| 主屏快捷指令书签 | 可以 |
| 应用内 bottom sheet | 不可以 |

小组件和控件由 Widget 扩展进程执行，不要求主应用运行（`E-12`）。
`OpenIntent` 会启动主应用并显示指定条目（`E-10`、`E-29`）。
App Shortcut 由 Shortcuts 运行时执行（`E-27`）。
证据：`E-10`、`E-12`、`E-27`、`E-29`。

## 4. 推荐入口优先级

优先级按“免打开程度、可达位置、版本门槛、配置成本”排序。

1. 主屏交互小组件，iOS 17.0 及以上。
2. 锁屏交互小组件，iOS 17.0 及以上。
3. 控制中心控件，iOS 18.0 及以上，配 `OpenIntent` 可进入指定工作区。
4. Action Button，iOS 17.0 或 18.0 及以上，机型受限。
5. 轻点背面加快捷指令，iOS 14.0 及以上。
6. 主屏快捷指令书签。
7. 应用内 `presentationDetents` bottom sheet，只在应用内。

前四项共用同一套 App Intent，建议一起评审。

## 5. 决策表

| 决策 | 选择 | 原因 | 备选路径 |
| --- | --- | --- | --- |
| 主屏入口 | 交互小组件 | 在主屏，用户添加一次即可用 | 主屏快捷指令书签 |
| 锁屏入口 | 交互小组件或控件 | 同一份代码复用 | 不提供锁屏入口 |
| 一键进入工作区 | 控制中心控件配 `OpenIntent` | 系统支持打开应用并显示指定条目 | 用 `widgetURL` 深链 |
| 硬件入口 | Action Button 放 App Shortcut 或控件 | 系统支持，无需常驻进程 | 不提供硬件入口 |
| 无版本门槛入口 | 轻点背面加快捷指令 | iOS 14 起可用 | 不提供 |
| 应用内手感 | `presentationDetents` | 系统原生，多个 detent 可拖动 | 自定义手势 |
| 主屏上滑手势 | 不采用 | 系统不提供注册接口 | 无 |
| 边缘手势 | 不采用 | 系统手势保留 | 无 |

## 6. 不采用方案

| 方案 | 风险 |
| --- | --- |
| 主屏上滑手势 | 不可实现，系统不提供注册接口（`E-02`） |
| 锁屏手势 | 不可实现，系统不提供注册接口（`E-02`） |
| 边缘手势 | 与系统手势冲突，违反设计指南（`E-06`） |
| 常驻后台进程模拟入口 | 与 iOS 后台限制冲突，且不属于本调研范围 |
| 越狱或私有接口 | 违反商店政策，签名不稳定 |

## 7. 限制和未决项

### 7.1 系统限制

1. 主屏、锁屏和边缘手势不对第三方应用开放（`E-02`、`E-03`、`E-04`、`E-06`）。
2. 锁定设备上小组件的按钮和开关不生效（`E-18`）。
3. 小组件中只有 `Button` 和 `Toggle` 支持交互，且必须使用 App Intent 初始化器（`E-17`）。
4. 所有系统空间入口都要求用户手动添加（`E-13`、`E-33`）。
5. Action Button 只存在于部分机型（`E-24`）。
6. 控件与小组件要求系统版本达到门槛（`E-07`、`E-15`）。

### 7.2 产品限制

1. 用户不添加入口时，入口完全不可见。
2. 轻点背面属于辅助功能设置，用户可能已在用其他动作。
3. 每个入口的首次使用都需要一次说明。
4. 低版本设备需要降级路径。

### 7.3 未决项

1. 轻点背面的实测延迟（`E-23`）。
2. 锁屏小组件按钮在锁定状态下的实际表现。
3. 控件在锁定设备上的认证语义细节。
4. 各入口在低电量模式和系统重启后的行为。
5. iOS 27 是否新增主屏接入面。
6. 入口实现由后续单独评审决定。
