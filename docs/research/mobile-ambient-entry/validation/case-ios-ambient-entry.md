## 4. V01：主屏手势不可用

### 4.1 前置条件

1. 设备已解锁，停留在主屏。
2. 应用已安装，且已定义至少一个 App Intent。
3. 设备未开启任何辅助功能手势替代方案。

### 4.2 命令或请求

按界面执行以下动作。

1. 在主屏空白区域从上向下滑动。
2. 在主屏空白区域从下向上滑动。
3. 从屏幕左边缘向右滑动。
4. 从屏幕右边缘向左滑动。
5. 在设置中查找“手势入口”或“主屏手势”一类项目。
6. 在快捷指令应用的动作列表中搜索主屏手势相关动作。

### 4.3 预期结果

1. 上述滑动全部由系统响应，不出现应用界面。
2. 设置中没有让第三方应用注册主屏手势的项目。
3. 快捷指令的动作列表中没有主屏手势类动作。
4. 主屏上唯一的第三方交互面是图标长按快速操作。
5. 长按应用图标出现的快速操作不超过 4 个，且会打开应用。

## 5. V02：主屏小组件按钮执行动作

### 5.1 前置条件

1. 系统版本不低于 iOS 17.0。
2. 应用定义了一个接收 App Intent 的 `Button` 或 `Toggle`。
3. 该 App Intent 的 `openAppWhenRun` 为 `false`，或 `supportedModes` 为后台模式。
4. 主屏上已添加该小组件。
5. 应用进程已从后台移除。

### 5.2 命令或请求

4. 从点按到状态更新有可见延迟。
