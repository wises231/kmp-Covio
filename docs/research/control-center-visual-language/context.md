# 前因与问题边界

> 本文件承载前因、研究问题、问题类别、适用边界、场景和成功标准。

主题索引见 [README.md](README.md)。技术分析见 [investigation.md](investigation.md)。

## 1. 问题类别与适用边界

### 1.1 研究问题

控制中心的内容按钮由哪些可复现的取值构成？Covio 工作台用哪些公开 API 能复现同一套表现？

### 1.2 问题定义

本文件处理一类问题：第三方界面要与系统自带界面表现一致，但系统组件的实现不公开。

表现一致指四类取值落在同一区间。

| 类别 | 一致的判据 |
| --- | --- |
| 几何 | 圆角与缝宽落在系统实测值的范围内 |
| 材质 | 填充的半透明度与模糊程度接近系统 |
| 边 | 边缘的高光与暗线由系统绘制，不是自绘描边 |
| 层级 | 哪些元素有玻璃、哪些没有，与系统相同 |

「表现一致」不要求像素级相同。
系统组件的内部实现不公开，像素级相同无法验证。

### 1.3 触发条件

1. 用户要求工作台的表现与控制中心一致。
2. 卡片用不透明填充，桌面上看不到模糊。
3. 内容区有一块统一底板，与控制中心的结构不同。
4. 设计合同定义了半透明材质取值，但没有组件使用。

### 1.4 问题分类

| 类别 | 表现 | 主要因素 | 推荐路径 |
| --- | --- | --- | --- |
| 几何不一致 | 圆角比例与缝宽来自设计稿，不来自系统 | 取值来源是设计稿 | 按控制中心实测值改 |
| 材质不一致 | 卡片是不透明色块，没有模糊 | 填充用了不透明的 `token/color/surface` | 换半透明材质填充，加玻璃底材 |
| 层级不一致 | 内容区有一块统一底板 | 早期版本用一块板包住全部内容 | 删掉底板，玻璃下放到每张卡片 |
| 边不一致 | 卡片自绘 1 点描边与投影 | 自己画边 | 交给 Liquid Glass 的镜面亮边 |
| 平台不一致 | 玻璃画不出来时界面不可用 | 没有降级路径 | 保留材质降级开关 |

### 1.5 适用范围

1. macOS 26 及以上的宿主。
2. `macosApp/` 里的 SwiftUI 视图。
3. 工作台的顶栏板、内容卡片与首页网格卡片。

### 1.6 范围外事项

1. 控制中心自身的私有实现。本文只做外部观察。
2. Windows 与 iOS 宿主的界面。
3. 菜单栏胶囊以外的系统组件，例如通知中心与聚焦。
4. 图标与字体资源。

### 1.7 受影响角色

| 角色 | 受影响的方式 |
| --- | --- |
| 终端用户 | 目视判断工作台是否与控制中心一致 |
| 界面研发 | 按本文的取值改视图代码 |
| 设计评审 | 用本文的实测值替代设计稿取值 |
| 无障碍用户 | 减弱动态效果与对比度设置下仍要可用 |

### 1.8 系统模型

```text
桌面壁纸
  -> WindowServer 合成
     -> 控制中心进程：私有模块视图（不公开）
     -> Covio 面板窗口：NSWindow（透明、无边框、非激活）
        -> SwiftUI 视图树
           -> glassEffect / Material
```

控制中心与 Covio 是两个独立进程。
两者都由 WindowServer 合成。
Covio 拿不到控制中心的视图树，只能从截图取样。

### 1.9 状态矩阵

| 状态 | 卡片玻璃 | 卡片填充 | 内容区底板 | 顶栏板 |
| --- | --- | --- | --- | --- |
| 正常（macOS 26 及以上） | `Glass.regular` | `token/color/material-thin` 半透明 | 无 | `Glass.regular` 胶囊 |
| 降级（玻璃不可用） | `.regularMaterial` | 同上 | 无 | `.regularMaterial` |
| 减弱动态效果 | 不变 | 不变 | 无 | 不变 |
| 全屏 Space | 不变 | 不变 | 无 | 隐藏 |
| 编辑模式 | 不变 | 不变 | 无 | 顶栏下多一条提示条 |
| 搜索有内容 | 不变 | 不变 | 无 | 内容列换成搜索结果 |

### 1.10 解决路径

按控制中心的实测值改工作台的取值。
玻璃下放到每张卡片，删掉内容区底板。
保留材质降级开关。

## 2. 场景定义

### 2.1 挂帘展开

用户从屏幕顶部唤出挂帘。
面板在指针所在屏幕的顶部中央展开。
顶栏板是胶囊，下面是卡片。
卡片之间露出桌面。
判据是卡片边缘有亮边，卡片内部能看到桌面的模糊。

### 2.2 内容区滚动

内容超过一屏时滚动。
卡片滚动时玻璃跟随卡片移动。
判据是滚动中卡片的模糊内容随之变化，不出现固定的底板。

### 2.3 编辑模式

用户进入编辑模式。
顶栏下多一条提示条。
首页卡片带删除钮与缩放手柄。
判据是提示条与卡片用同一种玻璃，卡片可拖动。

### 2.4 深色与浅色外观

系统外观切换时界面跟随。
判据是两种外观下卡片的填充与文字对比度都成立。

### 2.5 玻璃底材降级

`.glassEffect` 在无边框透明面板里画不出来时，界面仍要可用。
调试构建用 `COVIO_GLASS_SURFACE` 环境变量切换底材。
判据是四个取值都能起，界面不崩。

## 3. 成功标准

1. 用户在真机上目视确认每个卡片与控制中心的内容按钮表现一致。
2. 卡片之间露出桌面，内容区没有统一背板。
3. `bash scripts/test-all.sh` 全部通过。
4. 深色与浅色外观下都能看到卡片的模糊。
5. 四个玻璃底材取值都能起，界面不崩。
