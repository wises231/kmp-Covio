## 2. 目标

确认工作台的每个卡片与控制中心的内容按钮表现一致。
确认内容区没有统一底板。
确认玻璃不可用时界面仍然可用。

## 3. 范围

### 3.1 范围内

1. 顶栏板的底材、圆角与亮边。
2. 设置页卡片、首页网格卡片、首页空态提示块的底材与填充。
3. 内容区有没有底板。
4. 卡片之间的缝宽。
5. 深色与浅色外观。
6. 四个玻璃底材取值。
7. 减弱动态效果。
8. 编辑模式。
9. 收起态与展开动效的回归。

### 3.2 范围外

1. 控制中心自身的实现。
2. 菜单栏胶囊以外的系统组件。
3. Windows 与 iOS 宿主。
4. 图标与字体资源。
5. 设计合同的去留。按 `#115` 单独处理。

## 4. 当前事实

1. 代码在分支 `feature/shell-match-preview`，底材改动在 commit `6a65aea`。
2. `bash scripts/test-all.sh` 在改动后通过过一次。494 个测试，0 失败。
3. 玻璃底材的默认值是 `.glass`，走 `Glass.regular`。见 `E-13`。
4. 内容区没有底板，四张卡片各自套了玻璃。
5. 控制中心的实测取值见 [证据附录](../evidence.md) 的 `E-01` 到 `E-05`。
6. 用户尚未目视确认。

## 5. 成功标准

1. 用户目视确认卡片与控制中心的内容按钮表现一致。
2. 卡片之间露出桌面，内容区没有统一背板。
3. 深色与浅色外观下都能看到模糊。
4. 四个底材取值都能起，界面不崩。
5. `bash scripts/test-all.sh` 全部通过。
6. `docs/design/workbench-architecture.md` 第 6 节的版式表与实现一致。

## 6. 前置条件

1. 构建产物在 `build/xcode-dd/Build/Products/Debug/Covio.app`。
2. 同一时刻只有一个 Covio 实例在跑。
3. 屏幕已解锁。锁屏状态下截图不可用。
4. 桌面壁纸有明暗变化，便于观察模糊。
5. 控制中心可用，便于并排对照。

## 7. 风险

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 跨截图比较桌面内容变化 | 结论无效 | 同一次会话内切换底材，每步确认缝里的亮度没变 |
| 屏幕锁定 | 拿不到截图 | 停止验证，标记 `阻塞` |
| 另一个会话占用实例锁 | 应用起不来 | 先 `pgrep`，确认没有别的实例 |
| 玻璃在无边框透明面板里画不出来 | 卡片没有模糊 | 退回 `.material`，记录失败样本 |
| 目视判断带主观性 | 结论不可复核 | 每步都留截图，并在记录里写清楚判断依据 |

## 9. 证据要求

1. 每一步留一张全屏截图，文件名写进记录。
2. 记录截图时的菜单栏时钟，用来判断两次截图之间隔了多久。
3. 涉及底材对照的步骤，必须记录缝里的亮度，证明桌面没有变。
4. 失败时保留原始截图，并写清楚现象。
5. 不写完整隐私日志。截图里如果出现个人信息，先裁掉再存。
