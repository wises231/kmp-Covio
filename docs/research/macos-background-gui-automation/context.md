# 前因与问题边界

> 本文件承载通用方案的前因、问题类别、适用边界、场景和成功标准。
> 原研究文档的章节编号保留，便于后续证据引用。

## 1. 问题类别与适用边界

### 1.1 问题定义

本文处理一类 macOS 自动化问题。
后台程序需要控制图形应用或虚拟机。
调用方可能位于 `Background` 会话。
调用方可能来自 SSH 或 `launchd`。
调用方可能遇到锁屏、盒盖、注销或快速切换用户。
系统限制分为会话隔离、TCC、WindowServer 和电源策略。
解决方案必须按限制选择路径。
解决方案不能让后台进程绕过 TCC。

### 1.2 触发条件

满足任一条件时，本文适用。
1. 调用方不在目标 Aqua 会话。
2. 目标操作需要 WindowServer。
3. 目标操作需要首次 AppleEvent。
4. 目标操作需要 TCC 授权。
5. 目标操作需要保持盒盖状态下的主机运行。
6. 目标操作需要创建或控制虚拟机。

### 1.3 问题分类

| 类别 | 表现 | 主要根因 | 推荐路径 |
| --- | --- | --- | --- |
| 会话隔离 | 后台进程看不到 Aqua 服务 | `launchd` 域隔离 | Aqua 桥接 |
| 首次 AppleEvent | 首次连接超时或缺少授权 | TCC 和交互实例 | 解锁后授权 |
| 宿主 GUI 自动化 | 输入或截图失败 | WindowServer 锁屏状态 | 解锁后执行 |
| 无界面虚拟化 | 新建和启动不依赖 GUI | 后端选择 | QEMU 或 Virtualization.Framework |
| 客机 GUI 自动化 | 需要截图、按键和点击 | 宿主输入不可靠 | VNC、QMP 和串口 |
| 电源策略 | 盒盖后主机睡眠或断开 | 电源断言和系统策略 | `caffeinate` 和 `pmset` |
| 注销 | Aqua 上下文消失 | 会话生命周期结束 | 返回 `gui_session_unavailable` |

### 1.4 状态矩阵

| 状态 | 已有 VM | 新建 VM | 首次 AppleEvent | 宿主 GUI 输入 | 客机 VNC |
| --- | --- | --- | --- | --- | --- |
| 解锁 | 可用 | 可用 | 需要授权 | 可用 | 可用 |
| 锁屏 | 条件可用 | 通过 Aqua 桥接 | 条件可用 | 不可靠 | 可用 |
| 盒盖，AC 电源 | 条件可用 | 通过 Aqua 桥接 | 条件可用 | 不可靠 | 可用 |
| 盒盖，电池电源 | 条件可用 | 条件可用 | 条件可用 | 不可靠 | 可用 |
| 注销 | 不可用 | 不可用 | 不可用 | 不可用 | 不可用 |
| SSH | 通过 `VMBridge` | 通过 `VMBridge` | 条件可用 | 不可靠 | 可用 |
| 快速切换用户 | 条件可用 | 条件可用 | 条件可用 | 当前用户不可靠 | 可用 |

### 1.5 三条解决路径

Aqua 桥接路径使用 `VMBridge.app` 和 Aqua LaunchAgent。
Aqua 桥接路径处理 GUI 应用、AppleEvent 和 UTM。
无界面后端路径使用 QEMU、QMP、VNC 和串口。
无界面后端路径处理新 VM 和 CI 类型任务。
客机内部路径使用 SSH、串口或代理。
客机内部路径处理不依赖宿主 GUI 的任务。
宿主 GUI 合成输入在锁屏下不可靠。
注销后 Aqua 上下文不可恢复。

## 2. 场景定义

### 2.1 锁屏

锁屏状态保留用户登录会话。
锁屏状态停止显示用户界面。
锁屏状态通常阻止合成输入。
锁屏状态可以继续运行部分后台任务。
`CGSSessionScreenIsLocked` 表示屏幕锁定。
`IOConsoleLocked` 表示控制台锁定。
锁屏不等于注销。
锁屏不等于睡眠。
锁屏不等于关闭 UTM。

### 2.2 盒盖

盒盖可以触发显示关闭。
盒盖可以触发系统睡眠。
Apple Silicon Mac 可以使用外接电源和外接显示。
系统电源策略决定盒盖行为。
应用可以使用电源断言阻止空闲睡眠。
应用不能改变所有系统的硬件策略。
永久修改 `disablesleep` 有风险。
临时修改必须恢复原值。

### 2.3 注销

注销销毁当前 Aqua 会话。
注销后的 LaunchAgent 不保持 Aqua 上下文。
注销后的 UTM 图形进程会退出。
注销后 AppleEvent 目标不可用。
注销后应返回 `gui_session_unavailable`。

### 2.4 快速切换用户

快速切换用户会保留其他用户的会话。
快速切换用户会隔离当前用户的 GUI 输入。
快速切换用户可能使 AppleEvent 延迟或失败。
快速切换用户不等同于当前用户锁屏。
跨用户控制必须使用目标用户的 Aqua 域。
跨用户控制通常需要额外的系统权限。
首版不支持跨用户控制。

### 2.5 SSH 和后台会话

SSH 会话通常是 `Background` 或 `StandardIO`。
SSH 会话没有 Aqua 的 Mach bootstrap 上下文。
SSH 会话不能直接访问 Aqua GUI 服务。
SSH 会话可以通过 Unix socket 调用 Aqua 桥接。
Aqua 桥接再调用 UTM 或无界面后端。
此分段是推荐架构的核心。

### 2.6 成功标准

锁屏后，已有 VM 继续运行。
锁屏后，后台客户端可以查询状态。
锁屏后，后台客户端可以启动已有 VM。
锁屏后，后台客户端可以创建无界面 VM。
锁屏后，后台客户端可以启动无界面 VM。
锁屏后，后台客户端可以截图客机。
锁屏后，后台客户端可以发送键盘输入。
锁屏后，后台客户端可以发送鼠标输入。
解锁后，UTM GUI 状态保持一致。
注销后，系统给出明确错误。
权限缺失时，系统给出明确错误。
任务结束后，系统设置恢复原值。
