## 4. 当前事实

`E-05` 和 `E-06` 显示，有无 `PreventSystemSleep` 断言，合盖后都会进入完全睡眠。
`E-08` 和 `E-09` 显示，`disablesleep` 是系统级键。
`E-16` 和 `E-20` 显示，`SMAppService` 要求公证，两种签名配置都注册失败。
本机没有 Developer ID，只有自签名证书。
详见 [evidence.md](../evidence.md)。
